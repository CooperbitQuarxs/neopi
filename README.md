## Qué falta (trabajo pendiente)

Hasta que se complete la primera integración, trata este repositorio como un **marcador de posición**:

1. **Código** — el historial y las ramas estables del fork público todavía no se han publicado aquí.
2. **Traducción** — README, descripciones, notas de entrega y textos orientados al equipo en español.
3. **Identidad / front matter** — nombre del proyecto, descripción de GitHub, página de inicio, temas y presentación alineados con la dirección de Neo* (no con el upstream original del fork).
4. **Primer PR de sincronización** — cuando el front matter del fork público esté listo, se abrirá (o se empujará) la primera publicación hacia la rama por defecto de este repo.
5. **Reglas de protección de ramas** — protección de la rama por defecto, política de merge (commits de fusión), checks y quién puede empujar.
6. **Automatización de espejo** — sincronización desde el fork público hacia este destino privado (solo líneas estables / releases, según se acuerde).
7. **Releases y CI en la org** — si aplica, flujos de release y verificación del lado Cooperbit.

## Cómo leer esto

- El trabajo de diseño, issues y PRs de funcionalidad ocurre en el **fork público** enlazado arriba.
- Este repo privado existirá para el equipo Cooperbit: código publicado, historial de entregas y, más adelante, tableros/proyectos si se configuran.
- Nada de lo listado como pendiente implica que el proyecto esté abandonado; es la cola de puesta en marcha del espejo en la organización.
