- `compaction://`: read resolved compaction settings, next trigger boundaries, method order, async state and agent policy. Write JSON using the same schema as `/compact control`: `{"action":"propose","scope":"session","values":{"thresholdTokens":90000,"asyncEnabled":false}}`. Actions: `show`, `propose`, `set`, `reset`. Scopes: `session` default, `project`, `user`. Values: `enabled`, `thresholdPercent` 1..99 or -1, `thresholdTokens` positive integer or -1, `reserveTokens`, `keepRecentTokens` non-negative integers, `methodOrder` distinct remote/snapcompact/handoff/shake/soft, `asyncEnabled`, `midTurnEnabled`, `autoContinue`. One threshold clears the competing threshold. Reset accepts optional `keys`, otherwise all controls. Session reset restores settings-layer values, persistent reset removes that scope's keys. Proposals never apply changes. Agent policy defaults to propose-only; set/reset require explicit `compaction.agentControl: write`. You MUST NOT raise thresholds merely to avoid compaction.
